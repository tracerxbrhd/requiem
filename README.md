# Requiem

Requiem is a Discord server management and automation platform. It builds persistent
administrative workflows above Discord's native roles, permissions, channels and moderation
capabilities, while keeping Discord's authority intact.

The current milestone establishes the shared application core: server configuration,
role-based command access, persistence, and independent Discord bot and HTTP API processes.
Moderation is the first planned feature module. Its actions are not implemented yet.
